# The Rust-test ledger

> Generated by `scripts/rust_test_ledger.py --write` (port plan M8 part a); `--check` is the gate. Every test
> of pramana 1.3.0 (`rust-old/`), and where 2.0 carries it.

1.3.0 has **330** tests: the `#[test]`s of `rust-old/src` and `rust-old/tests`, and the crate docs' doc
tests. **319** are carried over, each as the Rust test states it, into the Cyrius test file and groups
below; **11** retire with the feature they tested. Beyond them, every value 1.3.0 computes is
a golden row replayed at 0 ulp (`tests/parity.tcyr`), so the carried tests are a second, independent check.
